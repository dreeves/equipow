m*(384) = 10

The result on the main page · Standalone exact verifier · Mathematica

This page is all Astra.

The claim is that 0, …, 383 can be partitioned into two sets with equal sums of powers of degrees 0 through 9, but cannot be partitioned with equal sums through degree 10. Degree 0 requires equal cardinalities. Shifting every position by 1 gives the same statement for 1, …, 384, by the binomial theorem.

Write the partition as signs ap ∈ {−1, +1}, with +1 on one part. “Order at least m” means Σp=0383 appk = 0 for 0 ≤ k < m. The proof below supplies both bounds. All arithmetic is integral; no numerical solver or assumption of symmetry is used to exclude order 11.

1. An explicit witness of order 10

Expand each hexadecimal digit below into four bits, most significant bit first, retaining leading zero bits. This gives 192 bits. Append those 192 bits in reverse order to obtain bits x0, …, x383, then put ap = 2xp − 1. This specifies every sign unambiguously.

C1BE1E21CD63D295A7887A5965A1EE1A56B4394C7B87827C

There are 192 plus signs and 192 minus signs. Direct integer evaluation gives

Σ appk = 0   (k = 0, …, 9),
Σ app10 = -8784705084103065600.

The verifier evaluates these sums directly. This proves m*(384) ≥ 10. The witness is the existing doubled order-9 construction at 192; its symmetry is used only to encode this example.

2. Only four residue-count patterns can have order 11

Suppose an order-11 partition exists, and let f(z) = Σ apzp. The polynomials C(p, k), for 0 ≤ k ≤ 10, form a basis for the polynomials of degree at most 10. Thus all eleven binomial moments vanish, so f and its first ten derivatives vanish at 1. Consequently (z − 1)11 divides f in ℤ[z]; the quotient has integer coefficients because the divisor is monic.

Let dr be the sum of signs at positions congruent to r mod 5, and let ℓ = (77, 77, 77, 77, 76) be the sizes of those five classes. Reducing (z − 1)11 modulo z5 − 1 gives the coefficient vector

g = (450, −450, 275, 0, −275).

Therefore d is an integer combination of the five cyclic shifts of g. Every shift satisfies the following linear conditions, so every possible d satisfies them:

Σ dr = 0,   dr ≡ 0 (mod 25),
d2 − 4d0 − 2d1 ≡ 0 (mod 125),
d3 − 3d0 − 3d1 ≡ 0 (mod 125).

Also |dr| ≤ ℓr and dr ≡ ℓr (mod 2). Hence each of d0, …, d3 lies in {−75, −25, 25, 75}, while d4 = −Σr=03 dr lies in {−50, 0, 50}. Checking the 44 choices leaves exactly the four rows below for the numbers of plus signs cr = (dr + ℓr)/2. These are necessary conditions only; no assertion of sufficiency is needed.

The same reduction can be checked by hand. Put er = dr/25. The first four entries belong to {−3, −1, 1, 3}, which contains exactly one representative of each nonzero residue mod 5; the fifth belongs to {−2, 0, 2}. Write a = e0 and b = e1 modulo 5. The two congruences give e2 ≡ 4a + 2b and e3 ≡ 3a + 3b. Since these entries are nonzero mod 5, b cannot be 3a or 4a. If b = a, all four entries have the same residue, hence the same integer value; their sum would force |e4| ≥ 4. Thus b = 2a. The four residues are then a, 2a, 3a, 4a, so their integer representatives are a permutation of −3, −1, 1, 3 and e4 = 0. The four choices for a give precisely the table.

3. The equations remaining after those positions are fixed

Put xp = (ap + 1)/2 ∈ {0, 1}. Define a 16-entry integer column

Ap = (C(p, 0), …, C(p, 10), [p ≡ 0], …, [p ≡ 4])T,

where the brackets are 0-or-1 indicators of congruence mod 5, and C(p, k) = 0 when k > p. For a row c of the table, the target is

b = (C(384, 1)/2, …, C(384, 11)/2, c0, …, c4)T.

Each half here is integral: modulo 2, (1 + z)384 = 1 + z128 + z256 + z384, so C(384, 1), …, C(384, 11) are even. The moment target follows from Σp=0383 C(p, k) = C(384, k + 1). Begin with class r all zero and class s all one. After inserting the exceptional one and removing the exceptional one, the remaining 230 variables must satisfy

Σp mod 5 ∉ {r,s} xpAp = R(i, j),
R(i, j) = b − Σt=076 As+5t − Ar+5i + As+5j.

A certificate consists of an integer modulus q and an integer row vector λ such that λ·Ap ≡ 0 (mod q) for every free position. Any integer solution must then satisfy λ·R(i, j) ≡ 0 (mod q). A nonzero residue proves that this case has no solution, even if the remaining variables are allowed to be arbitrary integers.

There is no need to trust how these vectors were found. For each row, compute λ·Ap for every free position 0 ≤ p < 384 and check divisibility by q. This is at most 8·230 evaluations. An alternative is to fix a free residue class h and expand λ·Ah+5t in C(t, 0), …, C(t, 10). Its coefficients are the first eleven forward differences at 0; checking each is divisible by q proves the identity for every nonnegative integer t.

Explicitly, for W(t) = λ·Ah+5t, define

ΔkW(0) = Σu=0k (−1)k−uC(k, u)W(u).

Since W has degree at most 10, the exact identity W(t) = Σk=010 ΔkW(0) C(t, k) holds. This reduces the divisibility check on each free residue class to eleven integer calculations.

Since B(t + 25) − B(t) = 25(t + 12) and every nonconstant coefficient of E is divisible by 25, E has period 25 in each variable modulo 625. At the four base pairs its integer values are −17,625, 15,375, −14,750, and 18,250, giving the four nonzero residues in the table. Each contradicts the required divisibility by 625.

Every possible order-11 partition would have appeared in one of these cases, and every case is impossible. An order greater than 11 would also satisfy all the order-11 equations, so it is excluded as well. Combined with the explicit witness, this proves m*(384) = 10.

6. Reproduce the checks

Save proof384.py and run it with Python 3.8 or later. It uses only the standard library, contains the witness and all certificate coefficients, and checks the generator congruences, complete count coverage, all free columns, all 23,716 cases, and the witness's exact moments.

python3 proof384.py

Mathematica: proof384.wl

wolframscript -file proof384.wl

The expected output is:

Astra: "m*(384) = 10; 4 vectores, 23716 casus, 0 superstites."

Its proof obligations remain active under python3 -O proof384.py. A failed obligation raises an error; an incomplete run is not a proof.

For independent checks of the numbers printed on this page, save this HTML file as proof384.html alongside the verifier, quals_proof384.py, quals_proof384_page.py, and index.html, then run:

python3 -m unittest quals_proof384 quals_proof384_page

The publication quals read the displayed hexadecimal witness and certificate tables from this HTML file and independently recompute the integer checks. They do not import the verifier's arithmetic or certificate constants. The verifier's own quals also reject corrupted certificates and missing coverage.
