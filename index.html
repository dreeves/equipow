    We extend the results of Table 2 of the paper by Buhler, Golan, Pratt, and Wagon (Math. Comp. 90, 2021) aka BGPW.

    Background: \(m^*(n)\) is the largest number \(m\) such that \(\{1, \ldots, n\}\) can be split into two parts whose power sums are equal — an equipowerful partition — for every exponent \(k = 0, \ldots, m - 1\).

    For example, if \(\{1, 2, 3, 4\}\) is partitioned into \(\{1, 4\}\) and \(\{2, 3\}\) then we have these power sums:

      \(k=0\):   \(1^0 + 4^0~=~2^0 + 3^0~=~2\)
      \(k=1\):   \(1^1 + 4^1~=~2^1 + 3^1~=~5\)
      \(k=2\):   \(1^2 + 4^2~= 17~\ne~2^2 + 3^2~=~13\).

    Since the power sums are equal for \(k = 0\) and \(k = 1\) but not for \(k = 2\), and since (exercise for the reader) no other bipartition of \(\{1, 2, 3, 4\}\) hits a bigger max \(k\), we say that \(m^*(4) = 2\) or that 4 has order 2.

    For \(\{1, \ldots, 8\}\) it turns out there's a bipartition — \(\{1, 4, 6, 7\}\) and \(\{2, 3, 5, 8\}\) — that gets us up to \(k = 2\), meaning \(m^*(8)\) is at least 3:

      \(k=0\):   \(1^0 + 4^0 + 6^0 + 7^0~=~2^0 + 3^0 + 5^0 + 8^0~=~4\)
      \(k=1\):   \(1^1 + 4^1 + 6^1 + 7^1~=~2^1 + 3^1 + 5^1 + 8^1~=~18\)
      \(k=2\):   \(1^2 + 4^2 + 6^2 + 7^2~=~2^2 + 3^2 + 5^2 + 8^2~=~102\)
      \(k=3\):   \(1^3 + 4^3 + 6^3 + 7^3~=~624~\ne~2^3 + 3^3 + 5^3 + 8^3~=~672\).

    Notice how the sum of the zeroth powers is just the number of elements. From that we see immediately that every odd \(n\) has order 0 because with an odd number of elements a set can't be partitioned into equal-size subsets, so \(k=0\) already fails.

    Fun fact, this property of having equal power sums for exponents from 0 up to some \(k\) is invariant under translating and scaling. In particular that means it doesn't matter if we use \(\{1, \ldots, n\}\) or \(\{0, \ldots, n - 1\}\) as the set to be partitioned — the \(m^*(n)\) values are the same. You can in fact start with any set of \(n\) equally spaced integers. From here on we use the convention that the \(n\)-element set to be partitioned is \(\{0, \ldots, n - 1\}\).

    So consider a bipartition of an \(n\)-element set that's equipowerful for all exponents \(\{0,\ldots,m-1\}\). We call such a bipartition a witness for order \(m\) because it establishes that a given length \(n\) has at least order \(m\).

    BGPW's Symmetry Conjecture: If a length \(n\) has a witness for order \(m\) then there exists a witness for order \(m\) that is symmetric (if \(m\) is even) or antisymmetric (if \(m\) is odd). Symmetry and antisymmetry are defined as follows. Start with \(\{0, \ldots, n-1\}\) and construct a parallel list of bits where a bit is 1 if the corresponding integer is in the first part of the bipartition and 0 if it's in the second. If the second half of that list of bits is the mirror image of the first half, the witness is symmetric. If the second half is the mirror image except with each bit flipped, the witness is antisymmetric.

    We represent (anti)symmetric witnesses as hex codes, following Table 5 of BGPW. Namely, take whichever of the two parts contains 0 to be the first part of the bipartition and construct the list of bits described above. Throw away the second half, since it's reconstructible by (anti)symmetry. Finally, treat the remaining bits (after right-padding) as a base-2 number and convert it to hexadecimal.

    Recovering a partition from a hex code reverses all that. Expand the hex code into \(n/2\) bits and take the positions of the 1s as the integers up to \(n/2\) to include in the first part of the bipartition. The integers past \(n/2\) to include in the first part are found by symmetry (if the order \(m\) is even) or by antisymmetry (if the order \(m\) is odd). By symmetry means duplicate the list of bits, reverse it, and append it to the original list of bits, i.e., mirror it to the right. By antisymmetry means duplicate, reverse, flip each bit, and append it, i.e., mirror the complement. Following is Mathematica code to do all that. When the code refers to a witness, it means a set of integers — the first part of a bipartition aka a witnessing set. 

    (* Find the order of witness A: the first exponent that's not equipowerful *)
wo[A_List, n_Integer] := 
  NestWhile[#+1&, 0, 2*Total[(A+1)^#] == Total[Range[n]^#]&]

(* Turn a hex code into a witness, given an even length n and order m *)
HexDecode[c_String, n_Integer, m_Integer] := With[
  {bits = Take[IntegerDigits[FromDigits[c, 16], 2, 4*StringLength[c]], n/2]},
  -1 + Flatten[Position[Join[bits, Reverse[If[EvenQ[m], bits, 1-bits]]], 1]]]

(* Turn a hex code into a witness without knowing the order *)
HexDecode[c_String, n_Integer] := 
  First@MaximalBy[HexDecode[c, n, #]& /@ {0,1}, wo[#, n]&]

    See BGPW for how a bipartition can be encoded as a Littlewood polynomial, meaning all coefficients are either \(+1\) or \(-1\), and how that's helpful for finding the orders for given lengths. The symbols \(\mathbin{\#}\) and \(\vee\) denote the expanded product and the join operation on Littlewood polynomials:
    \(f \mathbin{\#} g = f(x)\cdot g(x^{n_f})\)
    \(f \vee g = f(x) + x^{n_f} g(x)\),
    where \(n_f\) is the length of \(f\).

    The length of a Littlewood polynomial refers to the number of terms and the order is the multiplicity of the \(x=1\) root, i.e., the largest power of \(x-1\) that can be factored out of the polynomial. The expanded product and the join have these properties:

    • \(\operatorname{length}(f \mathbin{\#} g) = \operatorname{length}(f)\operatorname{length}(g)\)
    • \(\operatorname{order}(f \mathbin{\#} g) = \operatorname{order}(f)+\operatorname{order}(g)\)
    • \(\operatorname{length}(f \vee g) = \operatorname{length}(f)+\operatorname{length}(g)\)
    • \(\operatorname{order}(f \vee g) \ge \min(\operatorname{order}(f),\operatorname{order}(g))\)

    As mentioned above, odd numbers have order 0. Even numbers have order at least 1, because \(2k\) numbers can be partitioned into two equal-sized sets, i.e., an equipowerful partition for exponent 0.

    A short proof for why odd multiples of 2 have order 1 is as follows. For \(n\) to be an odd multiple of 2 means it's even but not divisible by 4, so twice an odd number. I.e., \(n = 2(2k+1)=4k+2\) for some \(k \ge 0\). As usual, we take our set of \(n\) numbers to be \(\{0, \ldots, n-1\}\). In this case that's \(\{0, 1, \ldots, 4k+1\}\). The sum of that set, by the standard formula for the sum of consecutive numbers, is \((4k+1)(4k+2)/2 = (4k+1)(2k+1)\). That's an odd times an odd, which is odd. (Simpler: Half of the numbers in \(\{0, \ldots, n-1\}\) are odd and the sum of any number of evens and an odd number of odds is odd.) So there's no bipartition that splits the sum in half, which means there's no equipowerful partition for exponent 1.

        Asymptotics

        Eyeballing Figures 1 and 2, it looks like maybe \(m^*(n) \approx 1.2\log_2 n\). What can we say about the asymptotics? For powers of two we already have this: \(m^*(2^k)/k \to c\) where \(c\) is at most \(2/\log_2 3 \approx 1.262\) and at least \(148/127 \approx 1.165\) based on the bounds we have for \(n=2^{127}\).

        Relatedly, the upper envelope of \(m^*(n)\) is at least \(\frac{12}{\log_2 480}\log_2 n \approx 1.347\log_2 n\) which we get from Theorem 4.1 (Multiplication) of BGPW which tells us that \(m^*(n^k) \ge k\,m^*(n)\). Namely, \(m^*(480^k) \ge 12k\) so for certain \(n\), \(m^*(n) \ge 12\log_{480} n = 12\log_2 n/\log_2 480 = \frac{12}{\log_2 480}\log_2 n\). So whenever we find a new high watermark for \(m^*(n)/\log_2 n\), that bumps up the upper envelope for the \(m^*\) function. UPDATE: The new best we have is 1440:16 (\(\href{#1440:16}{p_{1440}}\)). So \(16/\log_2 1440 \approx 1.525\) is the newest bound on the upper envelope.

        Claude on why the limit \(c\) exists, and its conjecture that \(c = 2/\log_2 3\)

        The limit \(c\) exists: Multiplication gives \(m^*(2^{a+b}) \ge m^*(2^a) + m^*(2^b)\), so by Fekete's lemma \(m^*(2^k)/k\) converges to its supremum. Its upper end is Boyd's bound (1997, Theorem 1), which the norm bound below sharpens: if a prime \(p\) does not divide \(n\), then \(m^*(n) \le \frac{p-1}{\log_2 p}\log_2 n\). At \(p = 3\) that is \(2/\log_2 3 \approx 1.262\). So only a multiple of 3, as \(1440 = 2^5 \cdot 3^2 \cdot 5\) is, can beat that ratio, and only a multiple of 15 can beat \(4/\log_2 5 \approx 1.723\).

        \(m^*(n)/\log_2 n\) has no limit: \(m^*(n)\) is 1 for every \(n \equiv 2 \pmod 4\) and at most 3 for every \(n \equiv 4 \pmod 8\) (BGPW's Theorem 4.1, Divisibility). Its limit superior is the upper envelope's ratio, \(U\), which Multiplication makes equal to \(\sup_n m^*(n)/\log_2 n\), so \(U \ge 16/\log_2 1440 \approx 1.525\).

        Claude conjectures that \(c = 2/\log_2 3\), the most the norm bound allows. For every \(k\) from 2 to 15, the upper bound from residue sums mod 3, 9 or 27 is attained at \(2^k\), as it is at 39 of the 43 multiples of 16 up to 1024 that are not multiples of 3. That pattern's next test is \(2^{16}\), where \(18 \le m^*(2^{16}) \le 19\). The lower end, \(148/127\), is no evidence against the conjecture: at \(2^k\), a join of products of Thue–Morse sequences and the page's sequences can show at most \(\frac{15}{\log_2 7360}k \approx 1.168k\). Since \(2^k\) is not a multiple of 3, one of the join's parts is not, nor is any of that part's factors. Each such factor's order is at most \(\frac{15}{\log_2 7360}\) times \(\log_2\) of its length: up to 2048 by the chart's upper bounds, the best there being 800's \(\frac{11}{\log_2 800} \approx 1.141\), and past it by the orders of the page's sequences, with equality at 7360. Thue–Morse's is exactly that logarithm.

        Past 1024, 1456 at order 12 would beat 800's ratio: \(12/\log_2 1456 \approx 1.142\). No sequence of length 1456 has order 12. Order 12 there makes every sign \(f_i\) with \(i \equiv 0 \pmod 3\) the same, since 729 must divide the differences of the residue sums mod 3. And \(P(i) = \sum_{k=0}^{11} \psi_k \binom{i}{k}\), with \(\psi = (659,\allowbreak 70,\allowbreak 659,\allowbreak 333,\allowbreak 336,\allowbreak 513,\allowbreak 216,\allowbreak 342,\allowbreak 522,\allowbreak 486,\allowbreak 81,\allowbreak 0)\), is a multiple of 729 at every other \(i < 1456\), while its values at the \(i \equiv 0 \pmod 3\) sum to 243 mod 729. Order 12 makes \(\sum_i f_i P(i) = 0\), so that sum would have to be a multiple of 729 (proof1456.py checks all of this). So \(m^*(1456) = 11\), the 11 from the join of \(\href{#432:11}{p_{432}}\) and \(\href{#1024:11}{p_{1024}}\).

        Whether \(U\) is finite is open. It is finite exactly when the least length of order \(m\) is at least \(a^m\) for some \(a > 1\), and how that length grows is BGPW's last question (§7). They place it between \(e^{(1+o(1))\sqrt m}\) and \(O(192^{m/9})\); 1440:16 lowers the latter to \(O(1440^{m/16})\), from about \(1.793^m\) to about \(1.575^m\). Boyd's bound \(m^*(n) \le (1+o(1))(\ln n)^2/\ln\ln n\) (1997, Remark 1) allows either.

        Claude on where the new results come from

        How the upper bounds are proven. Write a partition of \(0, 1, \ldots, n - 1\) as signs \(f_0, \ldots, f_{n-1}\), \(+1\) on one half and \(-1\) on the other, and let \(f(x) = f_0 + f_1x + \cdots + f_{n-1}x^{n-1}\). Order \(m\) means that \((x - 1)^m\) divides \(f(x)\). For a modulus \(M\), the residue sum \(D_r\) is the number of \(+1\)s minus the number of \(-1\)s at the positions \(i \equiv r \pmod{M}\). Reducing \(f(x)\) modulo \(x^M - 1\) leaves \(D_0 + D_1x + \cdots + D_{M-1}x^{M-1}\), which must still be a multiple of \((x - 1)^m\) modulo \(x^M - 1\). Each \(D_r\) also has the parity of its class's size and is at most that size in absolute value. The residue condition mod \(M\) rules out order \(m\) when an exhaustive search finds no residue sums that meet all of this.

        The norm bound for a prime \(p\) that does not divide \(n\) uses the same sums with \(M = p\). Let \(\zeta\) be a primitive \(p\)th root of unity. Then \(f(\zeta) = D_0 + D_1\zeta + \cdots + D_{p-1}\zeta^{p-1}\) is not 0: if it were, the \(D_r\) would all be equal, hence all 0, as they sum to \(f(1) = 0\); but since \(p\) does not divide \(n\), some class has an odd size and so an odd \(D_r\). It is a multiple of \((\zeta - 1)^m\), whose norm is \(p^m\), so the norm of \(f(\zeta)\), a positive integer, is at least \(p^m\). By the inequality of arithmetic and geometric means, that norm is also at most \((p \sum D_r^2 / (p - 1))^{(p-1)/2}\). With \(s_r\) the size of class \(r\) and \(|D_r| \le s_r\), order \(m\) needs \(p^{2m} (p - 1)^{p-1} \le (p \sum s_r^2)^{p-1}\).

        mstar.py and pow2.py repeat the search behind every residue claim each time they run. Certificates that can be checked on their own are still to be done.

        Claude explains how it found its examples

        The examples Claude found by searching, in the remarks above (\(\href{#320:9}{p_{320}}\), \(\href{#336:9}{q_{336}}\), \(\href{#432:11}{p_{432}}\), \(\href{#560:10}{p_{560}}\) and \(\href{#800:11}{p_{800}}\)) and in early runs at 144 and 240, came from one method: a search for the shortest vectors of a lattice, run with the C++ library fplll.

        Write a sequence as signs \(f_0, \ldots, f_{n-1}\) and let \(x_i = 2i - n + 1\), the positions centered on 0 and doubled. Order \(m\) means \(\sum f_i x_i^k = 0\) for \(k = 0, \ldots, m - 1\): by the fun fact above, these positions give the same order as \(0, \ldots, n - 1\), with smaller numbers. These are \(m\) linear equations in the signs. Claude looked only at symmetric sequences \((f_{n-1-i} = f_i)\) for even \(m\) and antisymmetric ones \((f_{n-1-i} = -f_i)\) for odd \(m\), BGPW's \((-1)^m\) convention. Since \(x_{n-1-i} = -x_i\), that leaves \(h = n/2\) unknown signs \(a_i = f_i\) \((i < h)\) and \(\lfloor m/2\rfloor\) equations, those with \(k\) of the same parity as \(m\); the others hold for every such sequence.

        Put \(a = 2y - 1\). The integer vectors \(y\) for which \(a\) solves the equations form a translate \(y_0 + K\) of the lattice \(K\) of integer solutions of the equations themselves, whose dimension is \(d = h - \lfloor m/2\rfloor\). (If there is no such \(y\), there is no such sequence.) So \(a\) ranges over the translate \(t + 2K\), where \(t = 2y_0 - 1\). Every vector in it has odd entries, so its squared length is at least \(h\), with equality exactly when every entry is \(\pm 1\); any other vector in it has an entry of absolute value at least 3, so its squared length is at least \(h + 8\). So the sequences sought are exactly the shortest vectors of \(t + 2K\), and finding them is a closest-vector problem: find the vectors of the lattice \(2K\) at distance \(\sqrt{h}\) from \(-t\).

        To search it, Claude reduced a basis \(b_1, \ldots, b_d\) of \(2K\) (LLL, then BKZ with block size 20) and enumerated. With \(b_1^*, \ldots, b_d^*\) its Gram–Schmidt vectors, the squared length of \(t + c_1b_1 + \cdots + c_db_d\) is a sum of \(d\) terms, one along each \(b_i^*\), and the term along \(b_i^*\) depends only on \(c_i, \ldots, c_d\). So the enumeration chooses \(c_d\), then \(c_{d-1}\), and so on, trying the integers at each step in order of the term they add (Schnorr–Euchner), and backs up as soon as the sum so far passes \(h\). That tree holds every solution: run to the end, it is an exhaustive search over the sequences of that symmetry, and when it ends empty it proves there are none.

        The tree grows about exponentially with \(d\), so Claude pruned it: once \(j\) of the \(d\) coefficients are chosen, the sum so far must be at most a fraction \(p_j\) of \(h\), with the fractions rising to \(p_d = 1\) (extreme pruning: Gama, Nguyen and Regev, Eurocrypt 2010). A pruned run visits a small part of the tree and finds a given solution with some probability. Randomizing the basis and reducing it again gives another, nearly independent try. In the early runs fplll's Pruner chose the fractions. Every example found was then checked with exact integer power sums.

        How Opus 5.5 ruled out order 12 at 432 and order 13 at 816

        Finding an example needs one sequence, and can look only at symmetric ones. Ruling an order out must cover every sequence, about \(2^n\) of them. These proofs do it with a tree, a pin tree: each node pins some residue sums \(D_r\) to given values, standing for the sequences with those sums; the root pins nothing; and every leaf is shown impossible. Three things make the tree small.

        The parity coset. The residue condition says that the residue sums mod \(M\), as a polynomial mod \(x^M - 1\), are a multiple of \((x - 1)^m\): they lie in a lattice \(L(M, m)\), with each \(D_r\) of the parity of its class's size. But mod 2 every sign is 1, so every sequence of length \(n\) is the same polynomial, \(S = (x^n - 1)/(x - 1)\). Dividing \(f\) by \((x - 1)^m\) therefore gives one fixed quotient mod 2, and so, mod a power of 2, the residue sums lie in a single coset of \(2L(M, m)\), which is far smaller. For order 12 at 432, mod 8, that leaves 5,450 vectors of 186,309. It holds for every sequence, symmetric or not.

        Certificates. Take a polynomial \(g\) of degree below \(m\) and a weight \(c_M(r)\) for each class of each pinned modulus, and let \(w(i) = g(i) + \sum_M c_M(i \bmod M)\). For a sequence of order \(m\) with those pins, \(\sum_i w(i) f_i\) is a number \(K\) known from the pins alone, \(\sum_M \sum_r c_M(r) D^{(M)}_r\), because \(\sum_i g(i) f_i = 0\). But \(|\sum_i w(i) f_i| \le \sum_i |w(i)|\). So if \(|K| > \sum_i |w(i)|\), no sequence has those pins. A linear program over \(-1 \le f_i \le 1\) finds such weights whenever the pins are impossible even for real numbers.

        Splitting. A node that no certificate closes splits on a further modulus. The same linear program bounds each residue sum of that modulus, and each bound is a certificate too; every vector of the lattice inside those bounds becomes a child. The modulus chosen is the one with fewest vectors, mostly 9, 11, 13 or 27. The tree's top pins 3, 5, 7, 4 and 8.

        It works here because 5 and 7 divide neither length, so the residue sums mod 5 and 7 cannot vanish, and the residue condition then forces them to be large. At 432, for order 12, the sums mod 5 must be \(\pm(75, 75, -50, -50, -50)\), on classes of 87, 87, 86, 86 and 86: two classes have only 6 signs out of 87 against the rest. A few such periodic patterns soon ask more of the signs than any can give, and nodes close quickly.

        • 432, order 12: 3,119 certificates, closing 7,561 nodes after 101 splits. About 15 CPU-minutes to make, 7 seconds to check.
        • 816, order 13: 187,269 certificates, closing 332,497 nodes after 6,269 splits. About 21 CPU-hours to make, 4 minutes to check.

        The linear program runs in floating point and only suggests. pintree.py replays a proof in exact integers with nothing but Python's standard library, and its docstring states the whole argument. pintree_second.py checks the same file with no code in common, enumerating and evaluating by other routes. Both accept the proof at 432 and the proof at 816, with the same counts. Each known sequence tried, asymmetric ones among them, survives the whole procedure at its own order.

        Other open cells have nodes where the residue sums are small and the linear program stays loose. Estimates for those run from hundreds of CPU-days to far more, so this method does not reach them yet. searches/pintree has the code that makes the proofs, the estimates and more of the details.

        Fable 5.2 explains form-tree proofs

        A form-tree proof shows that no sequence of length \(n\) has order \(m\). It is Opus 5.5's method of 2026-11-04, which settled \(m^*(288) = 9\), and it works as a pin tree does, in finer steps. A pin tree's node splits on a modulus, into a child for every vector of residue sums that the node allows. A form tree's node splits on one number, mostly into two children.

        Forms. A form is a linear form in the residue sums of one modulus: an integer weight \(w_r\) for each class \(r\) mod \(M\), a prime power. Its value on a sequence is \(v = \sum_r w_r D_r\), which is \(\sum_i w_{i \bmod M}\, f_i\). A single residue sum is a form.

        Grids. On sequences of order \(m\), a form's values are spread thin. Let \(L\) be the lattice of the multiples of \((x - 1)^m\) mod \(x^M - 1\), the \(L(M, m)\) above, or, when \(n < 2^m\), of the multiples of \((x - 1)^m (x + 1)\): then \(2^m\) divides \(f(-1)\), which is at most \(n\) in absolute value, so \(f(-1) = 0\). The residue sums mod \(M\) of a sequence of order \(m\) lie in \(L\), and in one coset of \(2L\), since the parity coset's argument holds at every \(M\), not only at powers of 2. So \(v \equiv c \pmod{2G}\), where \(G\) is the greatest common divisor of the form's values on \(L\), and \(c\) is its value on any vector of the coset. The values \(c + 2G\mathbb{Z}\) are the form's grid.

        A residue sum mod a prime \(p > m\) has \(G = 1\): its grid shows only its parity. Other weights do better. The Legendre symbol's weights, 1 on the nonzero squares mod \(p\), \(-1\) on the non-squares and 0 on the class of 0, have \(G\) a multiple of \(p\) once \(m > (p - 1)/2\), by a computation with Gauss's sum; at order 10 that is every odd prime up to 19. At prime moduli the prover, the program that builds the tree, takes its forms from short vectors of the lattice dual to \(L\): weights that are small for their \(G\), so that few values of the grid fall in the value's range.

        The tree. A node pins some forms to values and stands for the sequences of order \(m\) with those values. At a node, the prover takes a form that is not pinned there and bounds its value above and below, each bound by a certificate. If no value of the form's grid lies within the bounds, the node is closed: no sequence has its pins. If one value does, the form is pinned to it, in the same node. If several do, the node splits into a child for each. The top of the tree is a pin tree: it splits on the moduli 3, 5 and 7 in turn (at 152, 168 and 184, on 4 first), takes one vector of residue sums from each orbit under negation and reversal, and closes what it can by certificates. The vectors left are the form tree's start nodes. Reversal saves once more: where a node's sequences are closed under it and it changes the sign of a form's value, only the values \(v \ge 0\) get children. The proof is complete when every node is closed.

        Three steps from an earlier run at 288, taken from the first task of small.txt, one of the streams kept to test the checkers:

        • A form mod 13 has the grid \(13 + 26\mathbb{Z}\), and its two certificates put its value between \(-11\) and 61. So it is 13 or 39, and the node splits in two.
        • Two levels down, a form mod 8 has the grid \(256\mathbb{Z}\) and lies between \(-224\) and 245. So it is 0, and is pinned there.
        • In that node, a form mod 13 has the grid \(26\mathbb{Z}\) and lies between 27 and 46. No value is left, so the node is closed.

        Certificates. A certificate is as in a pin tree, with the node's pinned forms in place of its pinned classes. Take an integer \(c_q\) for each pin of the node, a form \(w^{(q)}\) mod \(M_q\) at the value \(v_q\), and a polynomial \(g\) of degree below \(m\) with integer values, and let \(W(i) = g(i) + \sum_q c_q\, w^{(q)}_{i \bmod M_q}\). Every sequence of the node has \(\sum_i W(i) f_i = K\), where \(K = \sum_q c_q v_q\), and no sequence at all has \(\bigl|\sum_i W(i) f_i\bigr| > \sum_i |W(i)|\). So if \(|K| > \sum_i |W(i)|\), the node is closed. To bound a form \(w\) mod \(M\), take an integer \(T > 0\) too: \(T v = K + \sum_i \bigl(T w_{i \bmod M} - W(i)\bigr) f_i \le K + \sum_i \bigl|T w_{i \bmod M} - W(i)\bigr|\). That bounds \(v\) above, and the same for \(-w\) bounds it below. Any such numbers give a true bound. A linear program over \(-1 \le f_i \le 1\) finds good ones, and the prover stops it once a tighter bound could exclude no further value of the grid.

        What checks it. The prover, pex.cpp, solves its linear programs in floating point and only suggests. It writes each step, with its certificates, to fkernel, a separate program in exact integers that takes nothing from the prover on trust. fkernel works out each form's grid from the lattice, each bound from its certificate and the children from those, and keeps its own list of the nodes still open, so a child left out, a value skipped or a node closed without a certificate makes it refuse. formtree.py, in Python with only the standard library, shares no code with fkernel, checks the same steps, and states the whole argument in its docstring. The work is cut into tasks. Each start node begins one, and a task that passes its time limit, four minutes in the run at 288, spills its unfinished nodes: each becomes a new task, named by a hash of its pins. fkernel gives each task a verdict: accepted or refused, with the names of the nodes it spilled. formtree.py's assemble command checks the top, whose certificates are kept, and confirms that every start node and every spilled node has an accepted verdict, with no node left open.

        Sizes. The proof at 288 has 16 start nodes, 205,491 tasks and 981,147,930 nodes, a spilled node counting in both of its tasks. Of those nodes, 466,813,767 split, into a little over two children each on average, and 1,470,167,061 times a form was pinned without a split. fkernel checked the tasks' 4,902,209,550 certificates as they were made. They would fill terabytes and were not kept, so checking them again means making them again, which took 104 hours with ten prover processes on Danny Reeves's Mac. The tasks' verdicts are kept, in run288v_snapshot.tar.gz. formtree.py read 1,841 of the tasks too, each of at most 14,448 nodes and 1,569,215 nodes in all, and agreed with fkernel on each. The proofs of single cells are small, 36,262 nodes at most, and both checkers read every task of theirs. For the chart's open cells, the same trees are estimated at about \(10^{10}\) nodes for order 14 at 480 and at \(10^{14}\) or more elsewhere; closing-step.md has the estimates, and ideas for closing nodes sooner.

        BGPW's Symmetry Conjecture through order 11

        The following is mostly Claude Opus 5.5 and maybe some Fable 5.1, before Fable 5.2:

        Claude on how the conjecture holds through order 11, and how far it reaches at orders 12 to 16

        BGPW conjecture (their §6) that if some sequence of length \(n\) has order \(m\), then some \((-1)^m\)-symmetric one does, with \(f_{n-1-i} = (-1)^m f_i\): symmetric for even \(m\), antisymmetric for odd \(m\). They proved it for \(m \le 8\) (their Theorem 3.2). Opus 5.5 has shown that it holds for every \(m \le 11\) and every \(n\), given the upper bounds listed below. A second Claude, writing its own code to look for an error, confirmed this and corrected that list.

        Where that leaves the conjecture:

        • Orders up to 8: proved by BGPW (their Theorem 3.2), from the upper bounds at 96, 152, 168, 176 and 184 listed below. Berend and Golan proved those at 96 and 152 by hand, and since 2026-11-09 form-tree proofs here check all five, those at 168, 176 and 184 for the first time.
        • Orders 9, 10 and 11: proved here at every length, from upper bounds that each have a checked proof. Two of those proofs came on 2026-11-09, by form trees: at 272, where the bound had come from BGPW's integer linear programs, which, they write, cannot be certified, and at 752, where it had come from a computation with no certificate. The bound at 144, which Berend and Golan proved by hand, got a second proof by form tree the same day.
        • Order 10 at 288: settled on 2026-11-08. The form-tree proof shows that no sequence of length 288 has order 10, so orders 9 to 11 are done, given those bounds.
        • Orders 12 and up: open. Astra’s construction gives a symmetric or antisymmetric sequence of exact order \(m\) at every admissible length \(n \ge 2^{Cm}\), for an absolute constant \(C\). At every order, finitely many small lengths remain, each needing its own computation. (Fable 5.2 chimes in: “Every order holds at every sufficiently large length, with no example needed: the theorem at the end of this section.”)

        Three facts reduce it to finitely many lengths.

        • Divisibility. If \(2^v\) is the largest power of 2 that divides \(n\), no sequence of length \(n\) has order \(2^v\) (BGPW's Theorem 4.1). So orders 9 to 11 need \(16 \mid n\).
        • Symmetry. The exact order of a symmetric sequence is even, and that of an antisymmetric one odd (BGPW's Theorem 4.1). So let \(s = (-1)^m\), let \(p\) have order \(m - 1\), whatever its symmetry, and let \(q\) be empty or \(s\)-symmetric of order \(m\). Then \(p \vee q \vee s p^*\), with \(p^*\) the reversal of \(p\), is \(s\)-symmetric of order \(m - 1\), and so of order \(m\).
        • A tail. Suppose every multiple of 16 from \(A\) to \(2A - 16\) has a sequence of order \(m - 1\). Then joins give one at every multiple of 16 from \(A\) on. With those as \(p\), an empty \(q\) gives an \((-1)^m\)-symmetric sequence of order \(m\) at every multiple of 32 from \(2A\) on, and a \(q\) of length \(b\), an odd multiple of 16, gives one at every odd multiple of 16 from \(2A + b\) on.

        For orders 9 to 11 these values work. The chart of \(m^*(n)\) above shows the orders needed from \(A\) to \(2A - 16\).

        • \(m = 10\): \(A = 320\), and \(b = 240\) for BGPW's symmetric example of order 10, so it holds for every \(n \ge 880\).
        • \(m = 11\): \(A = 528\), and \(b = 432\) for \(\href{#432:11}{p_{432}}\), so it holds for every \(n \ge 1488\).

        Now Fable 5.2 claims to have proved a weak version of the Symmetry Conjecture:

        Fable 5.2 on its proof that every order holds at every sufficiently large length

        Every order, every sufficiently large length. For every order \(m\) there is an \(n_0(m)\) such that every length \(n \ge n_0(m)\) that is a multiple of \(2^a\), the least power of 2 above \(m\), has a \((-1)^m\)-symmetric sequence of order \(m\). By Divisibility no other length has a sequence of order \(m\) at all. So at each order the conjecture holds from \(n_0(m)\) on, and can fail at only finitely many lengths.

        The proof uses no example and not Freiman and Litsyn's theorem. So what the three paragraphs above give for orders 12, 13, and 16, it gives for every order, with no example to find; and that theorem's statement about lengths follows from it, since a symmetric sequence is a sequence.

        The idea: a \((-1)^m\)-symmetric sequence of length \(2N\) is its right half, \(N\) signs \(\varepsilon_j\), and order \(m\) puts \(d = \lfloor m/2 \rfloor\) linear conditions on them, \(\sum_j \varepsilon_j u(j) = 0\), where \(u(j)\) is a vector of \(d\) integers, binomial coefficients in \(j\). The number of solutions is \(2^{N-d}\) times the integral of \(\prod_{j \le N} \cos(\pi\,\theta \cdot u(j))\) over a cube of side 2, one period of the product in each coordinate, which holds \(2^d\) integer points. A lemma shows that the product is smaller than any power of \(1/N\) unless \(\theta\) is close to an integer point: if the numbers \(\theta \cdot u(j)\) are mostly near integers, then along a long run of \(j\) those integers have vanishing differences of order \(m - 1\), so they are the values of one polynomial, and that pins \(\theta\) down. Near each integer point the product is the same Gaussian bump, up to its sign. The signs all agree exactly when \(2^a\) divides \(n\), by Lucas's theorem on binomial coefficients mod 2, and otherwise the bumps cancel. So of all the obstructions to order \(m\), only Divisibility survives at large lengths.

        At such lengths the number of \((-1)^m\)-symmetric sequences of order \(m\) is \(\bigl(1 + o(1)\bigr)\,2^N (2/\pi)^{d/2} / \sqrt{\det M_N}\), where \(M_N = \sum_{j \le N} u(j)\,u(j)^{\mathsf T}\) has determinant at most \(2^{m^2} N^{m(m-1)/2}\), and all but a vanishing share of them have exact order \(m\).

        0. Statement

        A sequence is \(f_0, \dots, f_{n-1} \in \{+1, -1\}\text{.}\) Its order is the largest \(k\) with \((x-1)^k \mid \sum_i f_i x^i\text{;}\) equivalently, with \(\sum_i f_i\, g(i) = 0\) for every polynomial \(g\) of degree below \(k\) (the derivatives of \(\sum_i f_i x^i\) at 1 are these sums for the falling factorials, which span those polynomials). (BGPW say “order \(m\)” for what is here “order at least \(m\)”, and “exact order” for “order”.) It is \(s\)-symmetric, \(s = \pm 1\text{,}\) if \(f_{n-1-i} = s f_i\text{.}\) For an order \(m\) write \(s = (-1)^m\) throughout, and let \(\operatorname{period}(m)\) be the least power of 2 above \(m\text{.}\) A length \(n\) is admissible (for \(m\text{)}\) if \(\operatorname{period}(m) \mid n\text{.}\)

        Theorem 1. For every \(m \ge 1\) there is an \(n_0(m)\) such that every admissible \(n \ge n_0(m)\) has a \((-1)^m\)-symmetric sequence of order at least \(m\text{.}\)

        Theorem 2. Let \(d = \lfloor m/2 \rfloor\text{.}\) The number of \((-1)^m\)-symmetric sequences of length \(n = 2N\) and order at least \(m\) is \(0\) if \(n\) is not admissible, and otherwise

        \(\displaystyle \bigl(1 + o(1)\bigr)\; 2^{N} \left(\frac{2}{\pi}\right)^{d/2} \frac{1}{\sqrt{\det M_N}} \qquad (N \to \infty),\)

        where \(M_N = \sum_{j=1}^{N} u(j)\,u(j)^{\mathsf T}\text{,}\) the \(u(j) \in \mathbb Z^d\) being the vectors of section 2, and \(0 \lt \det M_N \le 2^{m^2} N^{m(m-1)/2}\) for \(N \ge d\text{.}\)

        Corollary (BGPW's Symmetry Conjecture at large lengths). If \(n \ge n_0(m)\) and some sequence of length \(n\) has order at least \(m\text{,}\) then some \((-1)^m\)-symmetric sequence of length \(n\) has order at least \(m\text{.}\) Proof: by Divisibility \(n\) is admissible; apply Theorem 1. \(\square\) (For large \(n\) some such sequence has order exactly \(m\text{:}\) Remark 5.)

        So at each order the conjecture can fail at only finitely many lengths. Two more consequences: every sufficiently large admissible length has a sequence of order at least \(m\) (the corollary of Freiman and Litsyn's theorem that BGPW quote, proved here without it); and every order has \((-1)^m\)-symmetric sequences at lengths \(\operatorname{period}(m) \times \text{odd}\text{,}\) the examples that the Symmetry section's earlier argument for large lengths needed, and lacked for orders 14, 15 and 17 up.

        1. A symmetric sequence is its right half, under \(d\) linear conditions

        For \(m = 1\) both theorems are immediate: every antisymmetric sequence of even length sums to 0, and there are \(2^N\) of length \(2N\text{.}\) Let \(m \ge 2\) from here on.

        For \(\varepsilon = (\varepsilon_1, \dots, \varepsilon_N) \in \{\pm 1\}^N\) let \(\operatorname{mirror}(\varepsilon)\) be the sequence of length \(2N\) with \(f_{N-1+j} = \varepsilon_j\) and \(f_{N-j} = s\,\varepsilon_j\) for \(1 \le j \le N\text{:}\) that is \(s\varepsilon_N, \dots, s\varepsilon_1, \varepsilon_1, \dots, \varepsilon_N\text{.}\) It is \(s\)-symmetric, and every \(s\)-symmetric sequence of length \(2N\) is the mirror of exactly one \(\varepsilon\) (its right half, read outward from the middle).

        Let \(V\) be the real vector space of polynomials \(g\) of degree at most \(m - 2\) with \(g(1-x) = s\,g(x)\text{.}\) In the variable \(y = 2x - 1\) these are the polynomials of degree at most \(m-2\) and of the parity of \(m\text{,}\) so \(\dim V = d = \lfloor m/2 \rfloor\text{.}\)

        Lemma 1. \(\operatorname{mirror}(\varepsilon)\) has order at least \(m\) if and only if \(\sum_{j=1}^N \varepsilon_j\, g(j) = 0\) for every \(g \in V\text{.}\)

        Proof. The order is at least \(m\) iff \(\sum_i f_i\, h(i - N + 1) = 0\) for every polynomial \(h\) of degree below \(m\) (the shift is harmless). Position \(N - 1 + j\) contributes \(\varepsilon_j h(j)\) and position \(N - j\) contributes \(s \varepsilon_j h(1 - j)\text{,}\) so the sum is \(\sum_j \varepsilon_j \tilde h(j)\) with \(\tilde h(x) = h(x) + s\,h(1-x)\text{.}\) Now \(\tilde h(1-x) = s\,\tilde h(x)\text{,}\) and the coefficient of \(x^{m-1}\) in \(\tilde h\) is that of \(h\) times \(1 + s(-1)^{m-1} = 0\text{;}\) so \(\tilde h \in V\text{.}\) Every \(g \in V\) arises, from \(h = g/2\text{.}\) \(\square\)

        2. An integer basis of \(V\text{,}\) and the parity condition

        For \(0 \le k \lt d\) let

        \(\displaystyle b_k(x) = \binom{x+k-1}{2k} \quad (m \text{ even}),\)

        \(\displaystyle b_k(x) = \binom{x+k}{2k+1} + \binom{x+k-1}{2k+1} = \frac{2x-1}{2k+1}\binom{x+k-1}{2k} \quad (m \text{ odd}),\)

        and \(u(j) = (b_0(j), \dots, b_{d-1}(j)) \in \mathbb Z^d\text{.}\)

        Lemma 2. (i) Each \(b_k\) is in \(V\) and takes integer values at integers. (ii) \(b_k(j) = 0\) for \(1 \le j \le k\text{,}\) and \(b_k(k+1) = 1\text{.}\) (iii) The \(b_k\) are a basis of \(V\text{,}\) and a \(g \in V\) with \(g(1), \dots, g(d) \in \mathbb Z\) is an integer combination of them.

        Proof. (i) A binomial coefficient \(\binom{x+c}{r}\) is an integer at every integer \(x\text{,}\) negative ones included (for \(x + c \lt 0\) it is \((-1)^r\binom{r - x - c - 1}{r}\text{),}\) and for odd \(m\) the first form of \(b_k\) is a sum of two. Next, \((2k)!\binom{x+k-1}{2k} = \prod_{i=-k}^{k-1} (x + i)\text{,}\) and \(x \mapsto 1 - x\) sends the factor \(x + i\) to \(-(x + (-1-i))\text{,}\) permuting the \(2k\) factors with sign \((-1)^{2k}\text{:}\) so \(\binom{x+k-1}{2k}\) is unchanged, of degree \(2k \le m - 2\text{.}\) For odd \(m\) the factor \(2x - 1\) changes sign, and the degree is \(2k + 1 \le m - 2\text{.}\) The second form of \(b_k\) follows from \(\binom{a+1}{r+1} = \binom{a}{r}\frac{a+1}{r+1}\) and \(\binom{a}{r+1} = \binom{a}{r}\frac{a-r}{r+1}\) with \(a = x + k - 1\text{,}\) \(r = 2k\text{.}\) (ii) For \(1 \le j \le k\) the upper entries \(j + k - 1\) and \(j + k\) are nonnegative and below the lower ones. At \(j = k+1\text{:}\) \(\binom{2k}{2k} = 1\text{,}\) and \(\binom{2k+1}{2k+1} + \binom{2k}{2k+1} = 1\text{.}\) (iii) By (ii) the matrix \((b_k(j))_{1 \le j \le d,\ 0 \le k \lt d}\) is triangular with ones on its diagonal. So the \(d\) polynomials are independent, hence a basis of the \(d\)-dimensional \(V\text{;}\) and the coefficients of \(g\) solve a unitriangular integer system with right side \(g(1), \dots, g(d)\text{.}\) \(\square\)

        By Lemmas 1 and 2, \(\operatorname{mirror}(\varepsilon)\) has order at least \(m\) iff \(\sum_{j=1}^N \varepsilon_j\, u(j) = 0\text{.}\) Let \(A(N)\) be the number of such \(\varepsilon \in \{\pm1\}^N\text{,}\) and \(\sigma_k(N) = \sum_{j=1}^N b_k(j)\text{.}\)

        Lemma 3. (i) \(\sigma_k(N) \equiv \binom{N+k}{2k+1} \pmod 2\text{.}\) (ii) \(\sigma_k(N)\) is even for every \(k \lt d\) if and only if \(2N\) is admissible.

        Proof. (i) For even \(m\text{,}\) \(\sigma_k(N) = \sum_{t=k}^{N+k-1}\binom{t}{2k} = \binom{N+k}{2k+1}\text{.}\) For odd \(m\text{,}\) \(\sigma_k(N) = \binom{N+k+1}{2k+2} + \binom{N+k}{2k+2} = 2\binom{N+k}{2k+2} + \binom{N+k}{2k+1}\text{.}\)

        (ii) Let \(2^v\) be the largest power of 2 dividing \(N\text{.}\) Claim: the least \(k \ge 0\) with \(\binom{N+k}{2k+1}\) odd is \(2^v - 1\text{.}\) Take \(0 \le k \lt 2^v\) with binary digits \(k_0, \dots, k_{v-1}\text{.}\) Adding \(k\) to \(N\) carries nothing, so \(N + k\) has digits \(k_0, \dots, k_{v-1}\) in places \(0\) to \(v - 1\) and a 1 in place \(v\text{.}\) And \(2k + 1 \lt 2^{v+1}\) has a 1 in place 0 and \(k_{i-1}\) in place \(i\) for \(1 \le i \le v\text{.}\) By Lucas's theorem \(\binom{N+k}{2k+1}\) is odd iff each digit of \(2k+1\) is at most that of \(N + k\text{:}\) \(1 \le k_0\text{,}\) and \(k_{i-1} \le k_i\) for \(1 \le i \lt v\) (place \(v\) gives no condition; if \(v = 0\) then \(k = 0\) and place 0 holds a 1). That is \(k_0 = \dots = k_{v-1} = 1\text{:}\) \(k = 2^v - 1\text{.}\)

        So all \(\sigma_k(N)\text{,}\) \(k \lt d\text{,}\) are even iff \(d - 1 \lt 2^v - 1\text{,}\) i.e. \(2\lfloor m/2 \rfloor \lt 2^{v+1}\text{,}\) where \(2^{v+1}\) is the largest power of 2 dividing \(n = 2N\text{.}\) For even \(m\) this reads \(m \lt 2^{v+1}\text{.}\) For odd \(m\) it reads \(m - 1 \lt 2^{v+1}\text{,}\) the same as \(m \lt 2^{v+1}\) since \(m\) is odd and \(2^{v+1}\) even. And \(m \lt 2^{v+1}\) iff \(\operatorname{period}(m) \mid n\text{.}\) \(\square\)

        3. The count as an integral

        Let \(F(\theta) = \prod_{j=1}^N \cos\bigl(\pi\, \theta \cdot u(j)\bigr)\) for \(\theta \in \mathbb R^d\text{.}\)

        Lemma 4. If \(2N\) is not admissible then \(A(N) = 0\text{.}\) If it is, then \(F\) has every vector of \(\mathbb Z^d\) as a period and

        \(\displaystyle A(N) = 2^N \int_{[-1/2,\,1/2]^d} F(\theta)\, d\theta .\)

        Proof. \(\sum_j \varepsilon_j b_k(j) \equiv \sigma_k(N) \pmod 2\text{,}\) so an odd \(\sigma_k(N)\) leaves no solution. For \(w \in \mathbb Z^d\text{,}\) \(\int_{[0,1]^d} e^{2\pi i\, t \cdot w}\,dt\) is 1 if \(w = 0\) and 0 otherwise. So

        \(\displaystyle A(N) = \sum_\varepsilon \int_{[0,1]^d} e^{2\pi i\, t \cdot \sum_j \varepsilon_j u(j)}\,dt = \int_{[0,1]^d} \prod_j 2\cos\bigl(2\pi\, t \cdot u(j)\bigr)\,dt\)

        \(\displaystyle {} = 2^N \int_{[0,1]^d} F(2t)\,dt = 2^{N-d}\int_{[0,2]^d} F(\theta)\,d\theta .\)

        Adding the \(k\)-th unit vector to \(\theta\) multiplies \(F\) by \(\prod_j \cos(\pi b_k(j)) = (-1)^{\sigma_k(N)} = 1\text{.}\) So \(F\) is \(\mathbb Z^d\)-periodic, and its integral over \([0,2]^d\) is \(2^d\) times that over a unit cube. \(\square\)

        4. Phases near integers come from one integer polynomial

        Write \(\|x\|\) for the distance from \(x\) to the nearest integer. Let \(D = m - 2\) (the largest degree in \(V\text{),}\) \(D' = \max(D, 1)\text{,}\) \(J = \{1 - N, \dots, N\}\text{,}\) and

        \(\displaystyle C_m = 2^{\,2D^2 + 11D + 7} D' .\)

        Two classical inequalities for a real polynomial \(R\) of degree at most \(e\) and \(M = \max_{[\alpha, \beta]} |R|\text{,}\) \(\alpha \lt \beta\text{:}\)

        • Markov: \(\max_{[\alpha,\beta]} |R'| \le \dfrac{2e^2}{\beta - \alpha}\, M\text{.}\)
        • Chebyshev: for real \(x\) and \(\xi = \dfrac{2x - \alpha - \beta}{\beta - \alpha}\) with \(|\xi| \ge 1\text{:}\) \(|R(x)| \le M\,|T_{e}(\xi)| \le M\,(2|\xi|)^{e}\text{,}\) where \(T_e\) is the Chebyshev polynomial, \(|T_e(\xi)| \le (|\xi| + \sqrt{\xi^2 - 1})^e\text{.}\)

        Markov is used with \(e = D'\) (a polynomial of degree at most \(D\) has degree at most \(D'\text{),}\) Chebyshev with \(e = D\text{.}\)

        Sum-to-max bound. Let \(R\) have degree at most \(D'\text{,}\) let \(I\) be a set of \(L\) consecutive integers with \(L - 1 \ge 8D'^2\text{,}\) and \(S = \sum_{j \in I} R(j)^2\text{.}\) Then \(\max_{\operatorname{conv} I} |R| \le 4\sqrt 2\, D' \sqrt{S/(L-1)}\text{.}\)

        Proof. Let \([\alpha, \beta] = \operatorname{conv} I\text{,}\) \(M\) the maximum, attained at \(x_0\text{,}\) and \(h = (\beta-\alpha)/(4D'^2) \ge 2\text{.}\) By Markov, \(|R| \ge M/2\) within distance \(h\) of \(x_0\text{.}\) Since \(2h \le \beta - \alpha\text{,}\) one of \([x_0, x_0 + h]\text{,}\) \([x_0 - h, x_0]\) lies in \([\alpha, \beta]\text{;}\) it holds at least \(h - 1 \ge h/2\) integers, all in \(I\text{.}\) So \(S \ge (h/2)(M/2)^2\text{,}\) i.e. \(M^2 \le 8S/h = 32 D'^2 S/(L-1)\text{.}\) \(\square\)

        Lemma 5. Let \(K \ge 1\) and suppose \(\eta := C_m K^{D+1} N^{-1/2} \lt \tfrac12\text{.}\) Let \(q \in V\) with \(\sum_{j=1}^N \|q(j)\|^2 \le K\text{.}\) Then there is a \(P \in V\text{,}\) integer-valued at the integers, with \(|q(j) - P(j)| \le \eta\) for every \(j \in J\text{.}\)

        Proof. Since \(q(1-j) = s\,q(j)\) and \(j \mapsto 1 - j\) maps \(\{1, \dots, N\}\) onto the rest of \(J\text{,}\) \(\sum_{j \in J} \|q(j)\|^2 \le 2K\text{.}\) Let \(\delta = 2^{-D-2}\) and \(E = \{j \in J : \|q(j)\| \ge \delta\}\text{;}\) then \(|E| \le 2K/\delta^2 = K_1 := 2^{2D+5}K\text{.}\) From \(\eta \lt \frac12\text{:}\) \(N \gt 4C_m^2K^{2D+2} \ge 4K_1(8D'^2 + D + 2)\text{.}\)

        A long run. \(J \setminus E\) is a union of at most \(K_1 + 1\) runs of consecutive integers and has at least \(2N - K_1\) elements; let \(I\) be a longest run, of length \(L \ge (2N - K_1)/(K_1 + 1) \ge \frac78 N/K_1\text{,}\) so that \(L - 1 \ge N/(2K_1) \ge 8D'^2 + D + 2\text{.}\)

        An integer polynomial on the run. For \(j \in I\) let \(z_j\) be the integer nearest \(q(j)\) and \(r_j = q(j) - z_j\text{,}\) so \(|r_j| \lt \delta\text{.}\) For \(j, \dots, j + D + 1 \in I\text{,}\) the \((D+1)\)-th difference of \(q\) vanishes, so that of \(z\) equals minus that of \(r\text{,}\) which is below \(2^{D+1}\delta = \frac12\) in absolute value; being an integer, it is 0. So on \(I\text{,}\) \(z_j = P(j)\) for a polynomial \(P\) of degree at most \(D\text{,}\) integer-valued at the integers (Newton's forward formula from \(D + 1\) consecutive integer values).

        Small on the run, then on \(J\text{.}\) \(R = q - P\) has degree at most \(D\text{,}\) and \(\sum_{j \in I} R(j)^2 = \sum_{j\in I} \|q(j)\|^2 \le 2K\text{.}\) By the sum-to-max bound, on \(\operatorname{conv} I = [\alpha, \beta]\text{:}\) \(|R| \le 4\sqrt2\,D'\sqrt{2K/(L-1)} \le 8D'\sqrt{2K_1K/N} = 2^{D+6} D' K N^{-1/2}\text{.}\) For \(x \in [1-N, N]\text{,}\) \(|2x - \alpha - \beta| \le 2(2N-1)\text{,}\) so \(|\xi| \le 4N/(L-1) \le 8K_1\text{,}\) and by Chebyshev

        \(\displaystyle \max_{[1-N,\,N]} |R| \;\le\; 2^{D+6}D'K N^{-1/2}\,(16K_1)^D \;=\; 2^{2D^2+10D+6}D'\,K^{D+1}N^{-1/2} \;\le\; \eta .\)

        \(P\) is in \(V\text{.}\) For \(j \in J\) the integer \(P(1-j) - sP(j)\) equals \(sR(j) - R(1-j)\text{,}\) of absolute value at most \(2\eta \lt 1\text{;}\) so it is 0 at \(2N \gt D\) points, and \(P(1-x) = sP(x)\) identically. \(\square\)

        By Lemma 2(iii), \(P = z \cdot u\) for some \(z \in \mathbb Z^d\text{.}\) So with \(q = \theta \cdot u\text{,}\) Lemma 5 says: if \(\sum_{j \le N}\|\theta\cdot u(j)\|^2 \le K\text{,}\) then \(\theta \in W + \mathbb Z^d\), where

        \(\displaystyle W = \{\theta \in \mathbb R^d : |\theta \cdot u(j)| \le \eta \ \text{ for all } j \in J\}.\)

        Lemma 6. Let \(N \ge \max(d,\ 8D'^2 + 1)\text{.}\) (a) If \(\theta \in W\) then \(|\theta_k| \le B_m\eta\) for each \(k\text{,}\) where \(B_m = (1 + \max_{k \lt d,\ 1 \le j \le d} |b_k(j)|)^{d-1}\text{.}\) (b) If \(\theta^{\mathsf T} M_N\theta = \sum_{j=1}^N (\theta\cdot u(j))^2 \le \rho\text{,}\) then \(|\theta \cdot u(j)| \le 8D'10^D\sqrt{\rho/N}\) for all \(j \in J\text{.}\)

        Proof. (a) By Lemma 2(ii), \(\theta\cdot u(j) = \theta_{j-1} + \sum_{k \lt j-1}\theta_k b_k(j)\) for \(1 \le j \le d\text{;}\) induct on \(j\text{:}\) \(|\theta_{j-1}| \le \eta(1+\beta)^{j-1}\text{,}\) \(\beta\) the maximum in \(B_m\text{.}\) (b) The sum-to-max bound on \(I = \{1, \dots, N\}\) gives \(4\sqrt2 D'\sqrt{\rho/(N-1)} \le 8D'\sqrt{\rho/N}\) on \([1, N]\text{;}\) on \([1-N, N]\text{,}\) \(|\xi| \le (3N-1)/(N-1) \le 5\text{,}\) and Chebyshev gives the factor \(10^D\text{.}\) \(\square\)

        5. Proof of Theorems 1 and 2

        Let \(2N\) be admissible, \(K = m^2\ln N\text{,}\) and \(N\) so large that \(K \ge 1\text{,}\) \(N \ge \max(d, 8D'^2+1)\text{,}\) \(\eta = C_mK^{D+1}N^{-1/2} \le \frac14\) and \(B_m\eta \lt \frac12\text{.}\) Two bounds on a cosine:

        \(\displaystyle |\cos \pi x| \le e^{-\pi^2\|x\|^2/2}\ \ (x \in \mathbb R), \qquad \cos \pi x \ge e^{-(\pi^2x^2/2)(1 + \pi^2x^2/3)}\ \ (|x| \le \tfrac14).\)

        (For \(0 \le z \lt \pi/2\text{:}\) \((\ln\cos z)' = -\tan z \le -z\text{.}\) For \(0 \le z \le \pi/4\text{:}\) \(\tan\) is convex, so \(\tan z \le \frac4\pi z \le \sqrt2\,z\text{,}\) so \((z + \frac23z^3 - \tan z)' = 2z^2 - \tan^2 z \ge 0\text{,}\) so \((\ln\cos z + \frac{z^2}2 + \frac{z^4}6)' \ge 0\text{.)}\)

        Minor arcs. By Lemma 6(a), \(W \subset (-\frac12, \frac12)^d\text{.}\) Let \(\theta \in [-\frac12, \frac12]^d \setminus W\text{.}\) If \(\sum_j\|\theta\cdot u(j)\|^2 \le K\text{,}\) Lemma 5 would give \(z \in \mathbb Z^d\) with \(\theta - z \in W\text{,}\) so \(|z_k| \lt 1\text{,}\) \(z = 0\) and \(\theta \in W\text{.}\) Hence \(\sum_j \|\theta\cdot u(j)\|^2 \gt K\) and

        \(\displaystyle |F(\theta)| \le e^{-\pi^2K/2} = N^{-\pi^2m^2/2}.\)

        Major arc. On \(W\) every \(|\theta\cdot u(j)| \le \eta \le \frac14\text{,}\) so with \(Q(\theta) = \theta^{\mathsf T}M_N\theta\text{:}\)

        \(\displaystyle e^{-(\pi^2/2)(1 + \pi^2\eta^2/3)\,Q(\theta)} \;\le\; F(\theta) \;\le\; e^{-(\pi^2/2)\,Q(\theta)} .\)

        By Lemma 6(b), \(\{Q \le \rho\} \subset W\) whenever \(8D'10^D\sqrt{\rho/N} \le \eta\text{,}\) that is for \(\rho \le \rho_N := (C_mK^{D+1}/(8D'10^D))^2\text{;}\) and \(\rho_N \ge K^{2D+2} \to \infty\text{.}\) The matrix \(M_N\) is positive definite \(\text{(}u(1), \dots, u(d)\) are independent), with \(\det M_N \le \prod_k (M_N)_{kk} \le N^d(2N)^{2\sum_k \deg b_k} \le 2^{m^2}N^{m(m-1)/2}\text{,}\) since \(0 \le b_k(j) \le (2N)^{\deg b_k}\) for \(1 \le j \le N\) and \(d + 2\sum_k\deg b_k = m(m-1)/2\text{.}\) Let \(G = \int_{\mathbb R^d}e^{-(\pi^2/2)Q} = (2/\pi)^{d/2}(\det M_N)^{-1/2} \ge c_mN^{-m(m-1)/4}\text{.}\) Then

        \(\displaystyle \Bigl(1 + \tfrac{\pi^2\eta^2}3\Bigr)^{-d/2}\Pr\bigl[\chi^2_d \le \pi^2\rho_N\bigr]\,G \;\le\; \int_{\{Q \le \rho_N\}} F \;\le\; \int_W F \;\le\; G .\)

        Together. By Lemma 4, \(2^{-N}A(N) = \int_W F + \int_{[-1/2,1/2]^d\setminus W}F\text{,}\) and the second integral is at most \(N^{-\pi^2m^2/2} = o(G)\text{,}\) because \(\pi^2m^2/2 \gt m(m-1)/4\text{.}\) As \(N \to \infty\text{,}\) \(\eta \to 0\) and \(\rho_N \to \infty\text{,}\) so \(2^{-N}A(N) = (1 + o(1))\,G\text{:}\) Theorem 2. In particular \(A(N) \gt 0\) for all large admissible \(2N\text{:}\) Theorem 1. \(\square\)

        1. The size of \(n_0(m)\text{.}\) Every constant above is explicit, and they give \(n_0(m) = 2^{O(m^2)}\) (the binding conditions are \(\eta \le \frac14\) and \(B_m\eta \lt \frac12\text{,}\) with \(C_m = 2^{2D^2 + 11D + 7}D'\) and \(B_m = 2^{O(m^2)}\text{).}\) The conditions of section 5 as stated hold from about \(N = 2^{31}\) at \(m = 2\text{,}\) \(2^{221}\) at \(m = 5\) and \(2^{1062}\) at \(m = 12\text{:}\) far past any search, and far past the truth, which at \(m = 2\) is \(N = 2\text{.}\) From below, BGPW's Proposition 4.4 gives \(n \ge 2^m\) for any sequence of order \(m = 2^a - 1\) at a length \(2^a \times \text{odd}\text{;}\) the admissible length \(2^m - 2^a\) is such a length (for \(a \ge 2\text{),}\) so \(n_0(m) \gt 2^m - m - 1\) for those \(m\text{.}\)
        2. The limit is reached slowly. At \(m = 5\) and \(\theta = (-\frac1{16}, \frac14)\text{,}\) every phase \(\theta\cdot u(j)\) is at distance exactly \(\frac1{16}\) from an integer, so \(|F(\theta)| = \cos(\pi/16)^N\text{:}\) \(0.39\) at \(N = 48\text{,}\) \(0.02\) at \(N = 200\text{.}\) (With \(y = 2j - 1\) the phase is \(y(y^2 - 7)/96\text{,}\) and the integer \(y(y^2-7)/6\) modulo 16 depends only on \(y\) modulo 16; it is \(\pm 1\) in each of the eight cases.) A reviewer's search (branch and bound, \(N \le 128\text{)}\) found no minor arc at \(m = 5\) that decays more slowly. This arc and the others, whose signs change with \(N\text{,}\) put the number of antisymmetric sequences of order at least 5 between 0.55 and 3.6 times Theorem 2's main term at every admissible \(N\) from 16 to 48; at \(m = 6\) the ratio runs from 0.04 to 2.5 over the \(N\) from 24 to 48 with a sequence, and at \(m = 7\) and \(\theta = (-\frac1{32}, \frac18, \frac12)\) every phase is at distance exactly \(\frac1{32}\) from an integer, so that \(|F(\theta)| = \cos(\pi/32)^N\) is still \(0.38\) at \(N = 200\) (quals_symlarge.py checks these numbers). So the main term is no guide to counts at the lengths searches reach. The example also shows how far Lemma 5's \(\delta\) could be raised: its proof works for any \(\delta \le 2^{-D-1}\) (the difference it bounds is then below 1), and for \(D = 3\) no further, since here every \(\|q(j)\|\) is \(\frac1{16} = 2^{-D-1}\) and the nearest integers have fourth differences \(\pm 1\text{.}\)
        3. What this does not give. The lengths below \(n_0(m)\text{.}\) There the conjecture is, at each admissible length, either a symmetric sequence to exhibit or the absence of any sequence of that order to prove (as at 288 for order 10), and nothing here bears on either.
        4. Other symmetry. A \((-1)^{m+1}\)-symmetric sequence of order at least \(m\) has order at least \(m + 1\) (BGPW's Symmetry), so for it the theorems apply with \(m + 1\) in place of \(m\text{.}\)
        5. Exact order. For large admissible \(n\) some \((-1)^m\)-symmetric sequence of length \(n\) has order exactly \(m\text{;}\) indeed all but a vanishing fraction of those of order at least \(m\) do. A \((-1)^m\)-symmetric sequence of order at least \(m + 1\) has order at least \(m + 2\) (BGPW's Symmetry, with \(m + 2\) for their \(m\text{).}\) So the exceptions number \(A^{(m+2)}(N)\text{,}\) the count for \(m + 2\text{,}\) whose basis is \(b_0, \dots, b_d\text{:}\) the same \(b_k\) and one more. That count is 0 unless \(n\) is admissible for \(m + 2\text{.}\) If it is, Theorem 2 for \(m\) and for \(m + 2\) gives

          \(\displaystyle A^{(m+2)}(N)/A^{(m)}(N) = (1 + o(1))\sqrt{2/\pi}\,\bigl(\det M^{(m)}_N / \det M^{(m+2)}_N\bigr)^{1/2}\text{,}\)

          and the ratio of the two determinants (a leading block and the whole matrix) is \(1/\min_c \sum_{j \le N} R_c(j)^2\) with \(R_c = b_d - \sum_{k\lt d} c_k b_k\text{.}\) Each \(R_c\) has the degree \(e\) and the leading coefficient of \(b_d\text{,}\) so its \(e\)-th difference is the constant \(e!\) times that coefficient, which is 1 for even \(m\) and 2 for odd \(m\text{.}\) An \(e\)-th difference is at most \(2^e\) times the largest of the \(e + 1\) values it combines, so among any \(e + 1\) consecutive integers some \(|R_c(j)| \ge 2^{-e}\text{,}\) and \(\sum_{j \le N} R_c(j)^2 \ge \lfloor N/(e+1) \rfloor\, 4^{-e} \to \infty\text{.}\)

        It settles no open cell of the chart of \(m^*(n)\). Its constants give \(n_0(2) \le 2^{32}\), though every multiple of 4 has a symmetric sequence of order 2, and \(n_0(12) \le 2^{1063}\). Below \(n_0(m)\), each length that Divisibility allows still needs a \((-1)^m\)-symmetric sequence of order \(m\), or a proof that it has no sequence of order \(m\) at all, as at 288 for order 10.

        — Fable 5.2

        Astra on constructing sign sequences with the required symmetry at every sufficiently large admissible length, \(n_0(m)\le 2^{Cm}\)

        For some absolute constant \(C\), every order \(m\ge1\) and every multiple \(n\ge 2^{Cm}\) of the least power of two \(T\gt m\) admit a \((-1)^m\)-symmetric sequence of exact order \(m\), with each term either \(+1\) or \(-1\). The project’s Fourier argument gives a threshold \(2^{O(m^2)}\) and an asymptotic count. The construction here gives an explicit sequence. The finite-length Symmetry Conjecture remains open.

        A small initial defect

        Write \(s=(-1)^m\), \(d=\lfloor m/2\rfloor\). For a sequence of even length \(2N\), write the signs on the right half as \(e_1,\ldots,e_N\), counting outwards from the center. The left half is determined by reflection with sign \(s\). By Lemmas 1–3 of the project proof, the sequence has order at least \(m\) precisely when

        \(\displaystyle \sum_{t=1}^N e_t u(t)=0.\)

        Here \(u\) is an integer-valued vector polynomial of degree at most \(m-2\) with \(u(1-t)=s u(t)\). The vectors \(u(1),\ldots,u(d)\) form a basis of \(\mathbb Z^d\). At each admissible \(2N\), the sum of all \(u(t)\) is coordinatewise even. These facts come from the binomial basis in the linked lemmas. For order one, take all signs in the left half positive and all signs in the right half negative.

        Take \(m\ge2\), \(N_0=T/2\le m\), and set the first \(N_0\) signs to \(+1\). Their moment sum \(S\) is even. Write

        \(\displaystyle S/2=\sum_{j=1}^{d} c_j u(j),\qquad Q=\sum_j |c_j|.\)

        The basis property gives integer \(c_j\). To bound \(Q\), interpolate \(u(t)\) on the \(2d\) consecutive nodes \(1-d,\ldots,d\). Fold each node \(1-j\) onto \(j\) using the reflection identity. For \(1\le t\le d\) the interpolation coefficients have absolute sum one. For \(d\lt t\le N_0\) put \(y=t+d-1\), \(M=2d-1\). At node \(i\) in coordinates \(0,\ldots,M\), the absolute Lagrange coefficient is

        \(\displaystyle \binom yi\binom{y-i-1}{M-i}\le \binom yM\binom Mi.\)

        Thus the absolute sum is at most \(2^{y+M}\le 2^{5m/2}\). Folding can only decrease it. Summing over \(t\) and dividing by two gives \(Q\le (m/2)2^{5m/2}\).

        Cancel the defect using distinct signs

        Put \(K=2^{m-1}\) and \(a_k=(-1)^{\operatorname{popcount}(k)}\). For each positive integer \(h\),

        \(\displaystyle \sum_{k=0}^{K-1} a_k u(j+kh)=0.\)

        Indeed the left side applies \(m-1\) finite differences with step sizes \(h,2h,\ldots,2^{m-2}h\) to a polynomial of degree at most \(m-2\), up to an overall sign. Hence each occurrence of \(\sigma u(j)\) in \(S/2\), with \(\sigma=\pm1\), can be replaced by the sum of \(-\sigma a_k u(j+kh)\) over \(1\le k\lt K\).

        Number the \(Q\) occurrences by \(\ell=1,\ldots,Q\) and give each one step \(h_\ell=(d+1)(KQ+\ell)\). When \(Q\gt 0\), all positions \(j+kh_\ell\) used in these replacements exceed \(N_0\), since \(K\ge N_0\). They are distinct. Reduction modulo \(d+1\) determines \(j\). After subtracting \(j\) and dividing by \(d+1\), the remaining number lies in the band \(k(KQ+1),\ldots,k(KQ+Q)\). Successive bands are disjoint because \(kQ \lt KQ\) for \(k\lt K\). Within a band the number determines \(\ell\).

        Immediately after the first \(N_0\) signs, place a block \(W\) long enough to include every replacement position, rounding its length up to a positive multiple of \(T\). Prescribe the sign at each replacement position to be \(-\sigma a_k\). Choose the other signs arbitrarily. Append a total of \(K\) copies of \(W\) signed \(a_0,\ldots,a_{K-1}\), counting the first copy among the \(K\). For each offset in \(W\), the \(K\) occurrences form a Thue–Morse sum with step \(|W|\), so the appended part has zero moment sum. Now flip the prescribed signs in its first copy only. Their pre-flip sum was exactly \(S/2\). Flipping changes the sum by \(-S\).

        Reflect this completed right half with sign \(s\). Its full length \(L=2(N_0+K|W|)\) satisfies \(L\equiv T\pmod{2T}\). The largest replacement position is at most \(d+(K-1)(d+1)(KQ+Q)\), so both \(|W|\) and \(L\) are \(2^{O(m)}\) with absolute constants. The same construction works with an empty set of replacements.

        From one length to all large lengths

        Let \(H=2^m\), the length of the order-\(m\) Thue–Morse sequence. The integers \(L/T\) and \(H/T\) are coprime because the first is odd and the second is a power of two. Given an admissible \(n\), use an empty center when \(n/T\) is even, or one length-\(L\) sequence when it is odd. Write \(b\) for this center length. For \((n-b)/(2T)\ge (L/T)(H/T)\), it is a nonnegative combination of \(L/T\) and \(H/T\). Indeed some coefficient from \(0\) through \(H/T-1\) of \(L/T\) gives the required residue modulo \(H/T\), and the remainder is nonnegative.

        Concatenate the corresponding length-\(L\) and length-\(H\) sequences on one side, with their \(s\)-times reversal on the other. Every block has order at least \(m\), and the full sequence has the required symmetry. The uniform threshold \(L+2LH/T\) is \(2^{O(m)}\).

        For exact order, reserve a further \(2H\) positions, then put an order-\(m\) Thue–Morse block at each end of the resulting sequence with reflected signs. The degree-\(m\) Taylor coefficient at \(x=1\) changes by \(+2c\) or \(-2c\) according to the common sign chosen, where \(c\ne0\) is that coefficient of Thue–Morse. Translation of a block preserves its first nonzero Taylor coefficient. At least one choice gives a nonzero coefficient.

        \(\displaystyle n_0(m)\le L+2LH/T+2H=2^{O(m)}.\)

        The exponential scale is necessary for a uniform existence threshold. Take \(m=2^v-1\), \(v\ge2\). The admissible length \(2^m-2^v\) is an odd multiple of \(2^v\) below \(2^m\). BGPW’s Proposition 4.4 rules out any order-\(m\) sequence there. The conditional Symmetry Conjecture holds vacuously at such lengths.

        The Thue–Morse completion of a prescribed prefix and changes of selected signs have precedents in Roth, Siegel and Vardy. The project’s centered basis supplies the parity at the starting length. The quantitative step here is to realize its entire half-moment defect at distinct positions of a single completion. Publication priority for the resulting bound has not been established. Roth, Siegel and Vardy, Lemma 2.5 and §5.2 · Buhler, Golan, Pratt and Wagon, §§4 and 6

        For any odd prime \(p\), let \(A_r\) and \(D_r\) be the class sums modulo \(p\) of the alternating sequence and of the given sequence. The signs alternate within each class of the alternating sequence, so \(|A_r|\le1\). Each flipped sign changes one class sum by two. Consequently

        \(\sum_r |D_r-A_r|\le n-32768,\qquad \sum_r|D_r|\le n-32768+p.\)

          \(n = 512\):  \(m^* = 9\)

          Order 10 is ruled out by the residue conditions mod 3, 9 and 27.

          Astra: “A proof for 512 and 496”

          Astra: “The mod-3 residue profile comes from Claude Opus 5.5’s manual proof.

          Theorem. No sequence of 512 or 496 signs has order at least 10. Consequently \(m^*(512)=m^*(496)=9\).

          Proof. Suppose 512 signs \(a_1,\ldots,a_{512}\) witness order at least 10. Write

          \(\displaystyle f(x)=\sum_{j=1}^{512}a_jx^j=(x-1)^9g(x),\qquad g(1)=0,\qquad g(x)=\sum_{j\ge0}g_jx^j\in\mathbb Z[x].\)

          1. Four positive signs

          Let \(S_r,G_r\) be the coefficient sums of \(f,g\) in class \(r\bmod3\), so \(\sum_r S_r=f(1)=0\) and \(\sum_r G_r=g(1)=0\). Modulo \(x^3-1\), we have \((x-1)^3\equiv-3x(x-1)\), hence \((x-1)^9\equiv81(x^2-x)\). So every \(S_r\) is divisible by 81, and

          \(\displaystyle S_1-S_2=81(G_1+G_2-2G_0)=-243G_0.\)

          Both \(S_1\) and \(S_2\) are sums of 171 signs. Their difference is even and has magnitude at most \(342<2\cdot243\), so \(S_1=S_2\) and \(G_0=0\). Their common value is an odd multiple of 81 with magnitude \(|S_0|/2\le85\). Flipping all signs if necessary gives \(S_0=-162\). Thus exactly four of the 170 signs \(a_{3t}\) are positive.

          2. Their squares and cubes

          Cubing \((x-1)^3=(x^3-1)-3x(x-1)\) gives \((x-1)^9\equiv(x^3-1)^3\pmod9\). Collecting the exponents divisible by 3 gives

          \(\displaystyle\sum_{t=1}^{170}a_{3t}y^t\equiv(y-1)^3\sum_{t\ge0}g_{3t}y^t\pmod9.\)

          The last factor vanishes at \(1\) because \(G_0=0\). Thus the left side has a factor \((y-1)^4\) modulo 9, so its signed square and cube sums both vanish modulo 9.

          \(\displaystyle \sum_t a_{3t}t^k=\left.\left(y\frac{d}{dy}\right)^k\sum_t a_{3t}y^t\right|_{y=1}\equiv0\pmod9\qquad(k=2,3).\)

          The unsigned sums over \(t=1,\ldots,170\) are respectively \(6\) and \(0\) modulo 9. Hence the four positive indices satisfy

          \(\displaystyle \sum_{i=1}^4 t_i^2\equiv3,\qquad \sum_{i=1}^4 t_i^3\equiv0\pmod9.\)

          The square congruence forces exactly three of the four \(t_i\) to be coprime to 3. Their count is a multiple of 3 by reduction modulo 3, and it cannot be zero since then every square would vanish modulo 9. But those three cubes are each \(\pm1\bmod9\), and the fourth is zero. Three signs cannot sum to zero modulo 9.

          3. The shorter contradiction at 496

          Numbering the positions \(3,\ldots,498\) instead of \(0,\ldots,495\) multiplies \(f\) by \(x^3\) and preserves its order at 1. The class sizes are now \(166,165,165\). Applying Step 1 to the two odd-sized classes gives, up to sign, \((S_0,S_1,S_2)=(-162,81,81)\). There are exactly two positive signs among the 166 positions \(j=3t\).

          The signed cube sum again vanishes modulo 9. The cubes \(t^3\bmod9\) repeat \(1,-1,0\), so their sum from 1 to 166 is \(1\bmod9\). The two positive indices would therefore satisfy

          \(\displaystyle 2(t_1^3+t_2^3)\equiv1\pmod9,\qquad t_1^3+t_2^3\equiv5\pmod9,\)

          impossible because \(t_i^3\equiv0,\pm1\pmod9\).

          Finally, order 9 is attained at 512 by \(\prod_{j=0}^{8}(1-x^{2^j})\): binary expansion gives its 512 coefficients \(\pm1\), and its nine factors vanish simply at 1. BGPW’s order-9 example at 496, \(\href{#496:9}{p_{496}}\), supplies the other lower bound. \(\square\)”
